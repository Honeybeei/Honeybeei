## 🚀 About Me

I'm a generalist programmer who evolved from C programming at 42 to pursuing a versatile approach across the entire technology stack. I believe that mastering fundamental concepts enables rapid adaptation to new frameworks - once you grasp core principles, similar technologies become variations on familiar themes rather than unfamiliar territories.

- 🎓 Completed the 42 Common Core in January 2024 at **42 Seoul 🇰🇷**
- 🏫 Currently at **42 Wolfsburg 🇩🇪** pursuing **ML/AI** and **Mobile App** specializations
- 🤩 Passionate about creating end-to-end software solutions that tackle real-world problems

## 🌟 Generalist Philosophy

As I was nearing completion of my 42 core curriculum, ChatGPT emerged as a transformative force in software development. Through extensive use, I've come to recognize it as a double-edged sword. While AI tools dramatically boost developer productivity, relying on them without understanding core concepts risks turning developers into ineffective code generators.

My experience with generative AI has shaped my philosophy:

- Strive to be a generalist programmer with deep comprehension of core concepts and system architectures
- Leverage AI as a powerful tool for code generation and problem-solving while maintaining critical oversight
- Balance specialized technical knowledge with broad understanding across the stack
- Develop the judgment to know when to trust AI suggestions and when to apply first principles
